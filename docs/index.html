What's new in v2.0 Beta

Professional mixing engine
  • Beat-matched crossfades — the outgoing song is time-stretched to match the incoming BPM and dropped in on-beat.
  • 3-band EQ shifts during every transition.
  • Energy-aware set ordering that raises and breathes the intensity across the night.
  • DJ techno intros and staged mix builds (next mix prepared while the current one plays).
Auto folder scanning
  • Watch a folder and auto-mix new files as they appear.
  • Auto-build toggle and build-on-launch option in the console.
YouTube auto-fetch & download manager
  • Search & auto-fetch requested tracks from YouTube.
  • Background download manager with progress and per-download actions (play / cue / delete).
  • Load to Library imports every download straight into your song library.
  • Storage cap: 400 MB by default — the oldest files are pruned automatically.
DMX lighting control
  • Live DMX-512 output (Enttec USB DMX Pro) plus an on-console simulation — lights dance to the track.
Console & UI
  • Three-column layout: Song Library on the left, visualizer + queue in the middle, controls on the right.
  • Build progress shown above the queue, 6 visual themes, and cross-platform tooltips on every control.
  • Library fixes: larger rows, selection summary, and .opus track support.
Storage requirements. The v2.0 Beta YouTube download cache is capped at 400 MB by default (yt_cache_limit_mb) — old downloads are pruned oldest-first automatically. Cache and settings live in ~/.autodj/ (outside the app install), so upgrading from v1.0 keeps everything.

Install on Windows

  1. Download the Windows installer (or the portable ZIP for a no-install run).
  2. Run AutoDJ-Setup-1.0.0.exe and click through the wizard — no admin rights needed.
  3. Launch Auto DJ, drop in your songs, hit Start Auto DJ. First launch takes ~10–30 s.

Install on macOS

  1. Download the macOS ZIP (or DMG) built on Apple Silicon + Intel.
  2. Unzip and drag AutoDJ.app into Applications.
  3. First time: right-click the app → Open to allow the unsigned app past Gatekeeper.

Requirements. Windows 10/11 (64-bit) with the built-in Edge WebView2 runtime, or macOS 11+. Optional: Ollama (local AI) or a Google Gemini API key for AI features — everything else works offline.

Downloads. These buttons always fetch the newest installers from the project's public distribution repo — all files are built from the source and published automatically on every release.

Privacy. This page only hosts ready-to-run installers. No analytics, no trackers — clicking a button downloads a file to your computer, nothing else.

First-run security prompts & how to get past them

1 · Windows — SmartScreen

  • When launching the installer you may see "Windows protected your PC". That's SmartScreen reacting to an unsigned exe — it's our own build, not a threat.
  • Click More info → Run anyway. That's a one-time approval for the file.
  • To never see it for Auto DJ again: Windows Security → Virus & threat protection → Manage settings → Exclusions → add the Auto DJ install folder.

2 · macOS — DMG or ZIP

  • Open the DMG and drag AutoDJ.app into Applications (or unzip the ZIP and copy the app).
  • Gatekeeper may say "unidentified developer" or "Apple cannot verify this app". The app is unsigned (no paid Apple certificate), not malicious.
  • Fix it one of these ways:
    • Right-click AutoDJ.app → Open → click Open, or
    • System Settings → Privacy & Security → scroll to Security → "Open Anyway", or
    • Terminal: xattr -dr com.apple.quarantine "/Applications/AutoDJ.app" then open "/Applications/AutoDJ.app".

3 · macOS — Homebrew (no prompts at all)

  1. Install Homebrew (one-time) — brew.sh, or paste the installer command from that site in Terminal.
  2. Then run: brew install awssudiptapathak/autodj/autodj
  3. Launch Auto DJ from Applications — it opens with zero warnings, because Homebrew never marks the file as quarantined.
